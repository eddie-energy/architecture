---
title: Inter. Communication
---

The Interoperable Communication component implements a data model for the energy data accessed from potentially multiple Regional Data-sharing Infrastructures and potentially multiple AIIDA instances. In fact, this component also understands the different data models of the Regional Data-sharing Infrastructures and is able to convert them to a unified data model that is CIM-compliant. This data model along with mappings for the conversion are presented [here](../data-model-meter-data-portal/data-model-meter-data-portal.md).
