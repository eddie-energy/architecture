## Overview

The information required by the Consent Admin Portal of each country may vary. The Consent Admin Portal may require information provided in an automated way (e.g., via APIs), but also in a manual way (e.g., by visiting a website and accepting a consent request manually). The specific fields that can be submitted via APIs are collected by the Permission Facade and are presented [here](../../data-models/permission-facade/permission-facade.md). Information about manual processes (which relate to historical validated data) is presented [here](../../../03-context-and-scope/prerequisites/prerequisites.md) (categorized based on country).
