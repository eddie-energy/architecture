The Simulation Data Source allows testing the internal functionality of AIIDA.
It generates random measurement data at the specified interval for the following OBIS codes:

- 1-0:1.8.0
- 1-0:2.8.0
- 1-0:1.7.0
- 1-0:2.7.0

## Connection to Metering Devices and AIIDA

To use the simulation, a new Simulation Data Source in the AIIDA user interface needs to be created.
