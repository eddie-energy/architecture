The Enedis Datahub is a permission administrator and data access provider for historically validated data in France.
Enedis offers various APIs, including the [Data Connect API](https://datahub-enedis.fr/en/data-connect-en/), which is useful for EDDIE to manage data access. Through these APIs, Enedis provides the eligible parties with the means to obtain metering data on behalf of customers in France. The provided APIs are based on HTTP/REST principles and use an OAuth 2.0-based authorization scheme to access the data.
