The energy-related data received from the Regional Data-sharing Infrastructure is represented within the EDDIE Framework using the following data model. This model follows the [CIM](../../../08-crosscut-concepts/domain-models/cim/cim.md) data structure as derived from IEC62325-351 Ed.3.

<div align="center">
<img src="./figures/CIM transfer Data.png" width="1033">
</div>

A description of the attributes of this model is provided [here](../data-model-master-data/Class%20and%20attributes%20CIM%20Transfer%20Data%20Base.md). Notably, The Regional Data-sharing Infrastructure of each country may offer energy-related data in different formats. In such cases, the data from the Regional Data-sharing Infrastructure is converted to the common CIM data model (shown above). To achieve this conversion, we have formulated the mappings from each country-specific data model.

> Mappings to country-specific models are presented [here](./country-data-models/country-data-models.md).
