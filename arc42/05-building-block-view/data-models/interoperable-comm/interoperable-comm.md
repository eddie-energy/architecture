## Overview

The Interoperable Communication component implements the functionality to understand different data models for historical validated data, originating from different countries. In addition, this component converts these data models to a unified data model that is CIM-compliant. This data model along with mappings for the conversion are presented [here](../meter-data-portal/meter-data-portal.md). The data model used by AIIDA for real-time data is presented [here](../../data-models/aiida/aiida.md).
