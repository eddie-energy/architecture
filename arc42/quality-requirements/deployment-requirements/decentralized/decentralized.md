## Context

The EDDIE Framework needs to be installable on any computer or cloud computing environment under the control of the eligible party. There should be no need to have any centralized component. Thus, the EDDIE Framework needs to be decentralized, thereby allowing the eligible party to be the only one in control of handling the hosted Services and serving the customers.

## Stimulus
The eligible party deploys and operates the EDDIE Framework on the selected computing infrastructure.   

## Response
The EDDIE Framework provides the Services to the customers of the eligible party without any interactions with a centralized instance that gathers data from all the customers.
