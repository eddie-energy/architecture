# EDDIE Architecture

This repository hosts the documentation of the software architecture of EDDIE (European Distributed Data Infrastructure for Energy) which complies with [arc42](https://arc42.org/). EDDIE is a research project co-funded by the European Union's Horizon Innovation Actions under grant agreement No. 101069510.

There are 3 options to read the architecture documenation:
1. Visit the architecture website (pending).
1. [Set up the architecture website locally.](./eleventy/README.md)
1. [Navigate the files on GitHub.](./arc42/README.md)
