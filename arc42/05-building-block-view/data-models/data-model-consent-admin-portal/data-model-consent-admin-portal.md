title: Consent Admin Portal
---

The information required by the Consent Admin Portal of each country may vary. In fact, the Consent Admin Portal may require information provided in an automated way (e.g., via APIs), but also in a manual way (e.g., access a website and create an account).

> The overall process of interacting with the Consent Admin Portal and the Regional Data-sharing Infrastructure in general, is presented [here](../../../03-context-and-scope/prerequisites/access-to-historical-data/access-to-historical-data.md).
