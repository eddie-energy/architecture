## Regional Connectors
As mentioned at [Link](..\EDDIE_Framework.md), the architecture for the country specific regional connectors can have diffenerent architectures, due to f.e. legal constraints, energy providers, data models etc. Therefore EDDIE has to be able to handle generic requests for differnet types of connectors. This section should describe the main particularities of the connector for each country separately. In general, the regional connector provides the main connection for the customer / EP to interact with the system (via an interface), to forward that information to EDDIE core and to the database eventually, as well as to handle historic energy data from regional data hubs.
