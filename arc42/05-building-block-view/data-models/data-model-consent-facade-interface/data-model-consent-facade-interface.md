---
title: Consent Facade
---

The Consent Facade is responsible for gathering the necessary information from the consumer to establish that the consumer consent has been given to the eligible party. This information may vary based on the target country. For this reason, this information outlined in the two tables below. The first table shows the required fields that need to be filled in regardless of the target country, while the second table shows the additional fields that have to be filled in for the target country. All these fields are filled in by the consumer through the EP Website.

| Field | Description |
|-|-|
| Service | The service that the consumer want to use |
| Country | The host country of the consumer |
| Consent Portal | The portal of the persmission administrator |
| Data Family | The type of the data to be shared, e.g., historical validated data |
| Start Date | The start of the time period of the data to be shared |
| End Date | The end of the time period of the data to be shared |
| Granularity | The frequency of the data, e.g., hourly |
