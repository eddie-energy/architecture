**This is the CIM version of the master data model.**
 
In green you find the CIM entities, in blue the EDDIE specifics.
Some existing entities are enhanced with EDDIE attributes: you recognize them by the minus sign in front of the name.
I have reused some of the RoleTypes even though some names are not exactly identical. The Permission Administrator is added
 
CIM vs EDDIE/SGTF roles:

* Metered data **responsible** vs Metered data **administrator**
* Data provider vs Data **access** provider

The Permission Administrator is added
